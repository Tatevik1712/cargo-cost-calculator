Современное Fullstack-приложение для динамического расчета стоимости и сроков грузоперевозок. Система реализует гибридный подход к вычислениям: на стороне бэкенда выполняется парсинг локальных коммерческих прайс-листов крупных перевозчиков (**РТТК**, **БРЛ**) из CSV-файлов, а также интегрируется внешнее API **ТК «Деловые Линии»** для получения актуальных магистральных тарифов.

Проект организован по принципу **Monorepo** с жестким логическим разделением клиентской (`frontend`) и серверной (`backend`) частей, обеспечивая чистоту и поддерживаемость архитектуры.

---

## 🌟 Ключевые возможности

* **⚡ Динамический расчет (Debounce):** Общая масса и объем партии груза рассчитываются сервером «на лету» прямо во время изменения габаритов в форме. Интерфейс плавно обновляется без лишних перезагрузок и лишнего спама запросами благодаря задержке ввода.
* **📂 Умный парсинг сложных CSV:** Бэкенд на ходу обрабатывает оригинальные прайс-листы со сложной структурой склеенных маршрутов (например, `Чита - Иваново / Иваново - Чита`), очищает русские текстовые форматы цен (`140 000,00` -> `140000.0`) и автоматически определяет категорию требуемого транспорта (от 1.5 до 20 тонн) в зависимости от веса.
* **🔌 Гибридная интеграция:** Совмещает изолированные внутренние расчеты по таблицам с внешними сетевыми запросами к `API v2` Деловых Линий.
* **🛡️ Безопасность окружения:** Все API-ключи и конфигурации сред полностью вынесены в файлы переменных окружения `.env` и защищены от попадания в публичный репозиторий с помощью `.gitignore`.
* **💎 Современный интерфейс:** Минималистичный адаптивный дизайн на React + Tailwind CSS с использованием иконок `lucide-react`.

## 🚦 Инструкции по запуску

Для полноценной работы приложения необходимы установленные **Python 3.10+** и менеджер пакетов **Bun** (или Node.js / npm).

### 1. Настройка и запуск бэкенда (FastAPI)

1. Откройте терминал и перейдите в директорию сервера:
   ```bash
   cd backend
   ```
2. Создайте и активируйте виртуальное окружение:
    ```bash
   python3 -m venv .venv
    source .venv/bin/activate  # Для macOS/Linux
    или для Windows: .venv\Scripts\activate
    ```
3. Установите все необходимые зависимости:
     ```Bash
    pip install -r requirements.txt
     ```
4. Создайте файл .env в папке backend/ и пропишите туда конфигурационные ключи:
     ```Plaintext
    DELLIN_API_KEY=ваш_секретный_токен_деловых_линий
     ```
5. Запустите сервер разработки Uvicorn:
     ```Bash
    uvicorn main:app --reload --port 8000
     ```
- Локальный адрес сервера: http://127.0.0.1:8000
- Интерактивная документация API (Swagger UI): http://127.0.0.1:8000/docs

### 2. Настройка и запуск фронтенда (React + Vite)

1. Откройте новое окно терминала и перейдите в папку клиента:
      ```Bash
    cd frontend
      ```
2. Установите пакеты и зависимости:
      ```Bash
    bun install  # или: npm install
      ```
3. Запустите локальный сервер разработки Vite:
      ```Bash
    bun run dev  # или: npm run dev
      ```
- Интерфейс калькулятора откроется по адресу: http://localhost:5173 (или порту, указанному в консоли сборщика).

## 🛠️ Перспективы коммерческого масштабирования (Roadmap)

Для трансформации текущего MVP в отказоустойчивую Enterprise-систему намечены следующие шаги развития:

1. **Логирование и аудит (Audit Trail):** Внедрение библиотеки loguru для сквозного логирования входящих запросов, времени парсинга и ответов от внешних шлюзов. Это позволит оперативно расследовать инциденты расхождения цен.
2. **Кэширование тарифов (Caching):** Подключение Redis для кэширования ресурсоемких ответов API ТК на 12–24 часа, что снизит нагрузку на сетевые шлюзы, сэкономит лимиты запросов и сократит время отклика до <50мс.
3. **Повышение отказоустойчивости (Fault Tolerance):** Настройка жестких таймаутов (httpx.Timeout) на внешние запросы. В случае недоступности серверов Деловых Линий система продолжит бесперебойно отдавать локальные тарифы из CSV.
4. **Хранилище данных и Аналитика:** Интеграция реляционной СУБД (PostgreSQL через SQLAlchemy) для накопления истории расчетов. Это позволит менеджменту строить аналитические отчеты по популярным направлениям и оптимизировать логистические цепочки.
