# Cargo Cost Calculator

Веб-приложение для сравнения стоимости грузоперевозки у трёх транспортных
компаний одновременно: **Деловые линии** (через внешний API), **РТТК** и
**БРЛ** (по локальным прайс-листам). Пользователь заполняет параметры груза
и маршрут — получает три предложения, отсортированные по цене, и
рекомендацию по выбору.

## Возможности

- Расчёт объёма и веса партии груза по габаритам одного места и количеству мест.
- Автоматический подбор тоннажа машины по весу партии.
- Параллельный запрос к API «Деловых линий» + расчёт по прайсам РТТК/БРЛ.
- **Динамический** список городов «Откуда»/«Куда» — собирается из реальных
  прайс-файлов перевозчиков, без дублей (см. `ARCHITECTURE.md`).
- Загрузка новых прайс-файлов РТТК/БРЛ через админ-панель (JWT, роль `admin`).
- Экспорт результата расчёта в PDF.

## Технологии

**Backend:** Python, FastAPI, Pandas, Pydantic, JWT, Uvicorn.
**Frontend:** React, TypeScript, Vite, TanStack Router, Tailwind (shadcn/ui).

Подробное описание архитектуры — в [`ARCHITECTURE.md`](./ARCHITECTURE.md).

## Запуск проекта

### Требования

- Python 3.10+ и зависимости из `backend/requirements.txt`
- Node.js и зависимости из `frontend/package.json`
- [ngrok](https://ngrok.com/) — только для тестирования с внешним доступом

### Локальный запуск (backend)

```bash
cd backend
python -m venv venv && source venv/bin/activate   # если ещё не создано
pip install -r requirements.txt
python app/main.py
```

По умолчанию сервер поднимается на `http://localhost:8000`
(см. `HOST`/`PORT` в `backend/config/settings.py`).

### Локальный запуск (frontend)

```bash
cd frontend
npm install
npm run dev
```

Frontend по умолчанию на `http://localhost:8080` (уточните порт в выводе
`npm run dev`, если он отличается).

Убедитесь, что в `frontend/.env.local` указан правильный адрес бэкенда:

```
VITE_API_BASE_URL=http://localhost:8000
```

### Запуск с доступом извне (для тестирования)

Используется связка из трёх терминалов — так тестировщики могут открыть
приложение по внешней ссылке без полноценного деплоя:

```
Терминал 1:
frontend % npm run dev

Терминал 2:
cargo-cost-calculator % ngrok http 8000      # туннель к backend

Терминал 3:
cargo-cost-calculator % ngrok http 8080      # туннель к frontend
```

После запуска:
1. Скопируйте URL, который ngrok выдал для порта 8000, и пропишите его в
   `frontend/.env.local` как `VITE_API_BASE_URL` — затем перезапустите
   `npm run dev` (переменные окружения Vite читаются только при старте).
2. Отправьте тестировщику URL, который ngrok выдал для порта 8080.

> **Важно:** бесплатный ngrok показывает страницу-предупреждение при первом
> обращении браузера — из-за этого может показаться, что бэкенд блокирует
> запросы по CORS. Приложение уже отправляет заголовок
> `ngrok-skip-browser-warning: true` во всех запросах к API, поэтому это не
> должно повторяться — если ошибка снова появится, в первую очередь
> проверьте именно её (детали — в `DECISIONS.md`, ADR-003/ADR-004).

## Обновление прайс-файлов

Прайсы РТТК и БРЛ загружаются через `POST /api/admin/upload` (нужна
авторизация с ролью `admin`) и сохраняются в `backend/data/`. Формат — см.
раздел «Модель данных прайсов» в `ARCHITECTURE.md`: файл должен содержать
строки-заголовки маршрутов и строки тарифов по тоннажу машины.

## Известные ограничения

- Парсинг прайсов основан на эвристиках разбора текста заголовков маршрутов —
  чувствителен к изменению формата исходных Excel-файлов.
- Нет автоматических тестов (см. `TASKS.md`).
- Тестовое окружение зависит от ngrok — URL меняется при каждом перезапуске.

Полный список — в [`TASKS.md`](./TASKS.md) и [`CONTEXT.md`](./CONTEXT.md).
