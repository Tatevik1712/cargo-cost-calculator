# CHANGELOG.md

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).
## [Unreleased]

### Fixed 
- **Динамический список городов не подхватывался на фронтенде.**
  `CargoCalculator.tsx` инициализировал `cities` статическим списком
  `getAllCities()` и не обрабатывал ошибку промиса
  `getCitiesFromBackend().then(setCities)` (не было `.catch()`) — при любом
  сбое  загрузки список молча оставался статическим без единого признака
  ошибки в интерфейсе.
- **CORS-ошибка при обращении к бэкенду через бесплатный ngrok.**
  ngrok показывает интерстициальную HTML-страницу-предупреждение при первом
  обращении браузера, у которой отсутствует `Access-Control-Allow-Origin` —
  браузер интерпретировал это как блокировку CORS, хотя FastAPI-приложение
  (с уже настроенным `CORSMiddleware`, `allow_origins=["*"]`) до запроса не
  доходило. Добавлен заголовок `ngrok-skip-browser-warning: true` во все
  fetch-запросы (`calc.ts`, `CargoCalculator.tsx`).

### Changed
- Список городов «Откуда»/«Куда» теперь полностью динамический — берётся из
  `GET /api/v1/cities`, который собирает и дедуплицирует города из
  прайс-файлов РТТК и БРЛ (`LocalCalculatorService.get_available_cities()`).
- `getCitiesFromBackend()` и `calculateOnBackend()`/`onCalc()` больше не
  «проглатывают» ошибки сети молча — ошибка пробрасывается наружу и
  отображается в UI.
- В `CargoCalculator.tsx` добавлены явные состояния `citiesLoading` и
  `citiesError` с индикацией в форме, выпадающие списки городов блокируются
  до успешной загрузки.

### Removed
- Статический список городов `getAllCities()` полностью удалён из `calc.ts`.
- Тип доставки «Экспресс» убран из формы, стейта и запроса на расчёт —
  поддерживается только «Авто».

## Как далее вести этот файл

При каждой логически завершённой задаче — добавляйте запись в раздел
`[Unreleased]` по категориям `Added` / `Changed` / `Fixed` / `Removed`.
При релизе — переносите накопленные записи под новую версионную секцию
(например, `## [1.1.0] — 2026-08-05`) и начинайте `[Unreleased]` заново.
